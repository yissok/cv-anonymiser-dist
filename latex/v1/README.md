# Browser LaTeX compiler assets

SwiftLaTeX's pdfTeX WebAssembly engine and a TeX Live subset are served from this
site. The application loads them only after Compile PDF is pressed. The worker
caches these public assets with Cache Storage; CV source and generated PDFs are
never written to that cache. Each file is checked against its generated byte count
and SHA-256 digest. Hash-based keys reuse unchanged files across release URLs.
Unreadable or damaged cached entries are removed, and interrupted network reads
retry once with HTTP-cache reload. Cached responses are reconstructed from fully
read bytes without HTTP Content-Length/Content-Encoding headers. Cache writes run
in the background so slow storage does not delay compilation. Loading reports
byte progress and treats 45 seconds without data as a stalled request; slow but
active transfers can continue within the startup time limit. There are no remote
compilation or package services.

Engine and base TeX files: https://github.com/sean-reid/latex-preview at
f80f84659c9476e41ef7212f6d753e10f6bd4af5. The engine originates from
https://github.com/SwiftLaTeX/SwiftLaTeX. Its EPL-2.0 / GPL-2.0 with Classpath
Exception notice is preserved in swiftlatex.LICENSE.txt. This copy changes the
loader to accept a preloaded wasm binary, resolve files from a bundled map,
disable network/bitmap-font lookups and omit the unconditional BibTeX invocation
for this single-file editor. The source remains in swiftlatexpdftex.js.

Additional TeX Live 2020 final packages: carlito, ragged2e, needspace, fontaxes,
xkeyval, iftex, everysel, cmap (including its character mapping resources), from https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2020/tlnet-final/archive/.
Their metadata and license declarations are retained in texlive-package-notices.txt;
TeX source files keep their original copyright/license headers. Carlito fonts use
the SIL Open Font License (carlito.LICENSE.txt); their LaTeX support files use the LPPL (see carlito.README.txt). Other bundled
TeX files retain their upstream licenses, principally LPPL and the Knuth license.
The base subset's expl3.sty compatibility stub is inherited from Sean Reid's tree.

tex-files.bin is a gzip stream (an opaque .bin filename avoids automatic HTTP
Content-Encoding decompression by static hosts). It contains a four-byte little-endian JSON-header
length, a JSON array of [kpathsea-format/filename, byte-offset, byte-length] entries,
and the concatenated original files. The worker uses native DecompressionStream;
no archive library is needed. The font map is trimmed to bundled fonts.

scripts/prepare-latex-assets.py rebuilds the assets from existing upstream archives
without network access. asset-info.json records input hashes, decoded asset hashes
and exact output sizes. The script also embeds the expected asset sizes/hashes in
compiler-worker.js so cache hits do not need a separate metadata download.
Rebuild after changing bundled files; their hashes automatically invalidate only
changed cache entries. Change the cache name for incompatible cache formats, and
increment the v1 directory for incompatible worker protocols or bundle formats.
