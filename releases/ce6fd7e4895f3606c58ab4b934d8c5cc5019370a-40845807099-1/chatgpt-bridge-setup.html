Set up ChatGPT Browser Bridge

Connect this app to your signed-in ChatGPT browser session once. Then paste a job description and choose Tailor CV with ChatGPT.

Install the extension

  1. Open chrome://extensions, brave://extensions or edge://extensions in your desktop browser.
  2. Enable Developer mode and choose Load unpacked.
  3. Select the extension folder in your separate chatgpt-browser-bridge repository. On Andrea’s Mac it is /Users/andrea/Documents/GIT/chatgpt-browser-bridge/extension. No build or local server is required.
  4. Open ChatGPT and sign in in the same browser profile.
  5. Reload CV Anonymiser. The tailoring panel should show Browser extension connected; use Check to retry.

Tailor a CV

  1. Import or open your full master CV. Set up and review your private redactions.
  2. Use Project ranking to order projects by personal priority and add notes about effort or limitations. These preferences save with your full master, browser workspace and private backup.
  3. Paste only the job description and choose Tailor CV with ChatGPT. The CV headline stays Software Engineer; no Company or Role fields need filling.
  4. Keep the app open while the extension scores every project’s job relevance, selects projects and requests the tailored draft in its dedicated ChatGPT tabs. Scores are estimates of fit, separate from your personal ranking.
  5. Review Project relevance. Compare all scores, swap or reorder picks, then use Draft selected projects to draft your chosen list.
  6. Review the returned CV. In Refine generated text, edit Core skills or a project manually, or give ChatGPT feedback for that block. Review and apply each proposed revision. Resolve or acknowledge any Draft check notices before exporting or saving.
  7. Save the application or choose Compile PDF yourself when ready. Check the actual page count and layout.

Only prepared prompts are sent through the extension. Your private redaction key stays in this app. Details you have not selected for redaction may still appear in the prompts, including project notes and revision feedback. You can review selection and drafting prompts using the manual controls and copy individual revision prompts before sending them.

When it needs attention

Sign-in, browser verification, a changed ChatGPT layout or an uncertain Send can pause a request. Inspect its dedicated ChatGPT tab before starting another run. Account message limits wait through shared cooldowns. Cancel tailoring stops pending work; edits to the current workspace also cancel the run and keep your edits.

After installing or reloading the extension, reload this page’s CV app. Use the same browser profile for the app, extension and ChatGPT. The original copy-and-paste workflow remains under Copy and paste prompts manually.

The bridge supports the hosted CV Anonymiser addresses and local development at http://localhost or http://127.0.0.1. Unpublished changes can be tried with npm run dev -- --host 127.0.0.1 in the CV repository.
