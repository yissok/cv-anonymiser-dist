Set up ChatGPT Browser Bridge

Connect this app to your signed-in ChatGPT browser session once. Then paste a job description and choose Tailor CV with ChatGPT.

Open the setup wizard to download both extensions and check this computer. Or download the ChatGPT extension ZIP directly.

Firefox 140 or newer

Download Firefox bridge ZIP. This is a testing build. A permanent Mozilla-signed release has not yet been published.

  1. Open about:debugging#/runtime/this-firefox in desktop Firefox.
  2. Choose Load Temporary Add-on and select the downloaded ZIP, or extract it and select manifest.json.
  3. In the add-on’s permissions, allow access to ChatGPT and the CV app. Sign in to ChatGPT in the same Firefox profile, reload the CV app and check its extension connection.
  4. After restarting Firefox, load the testing add-on again. Permanent installation requires Mozilla signing; keep Firefox’s signature checks enabled.

Firefox uses the same automatic master creation, advice and tailoring flow. The separate Google connection extension is still Chromium-only; local CV storage works without it.

Install in Chrome, Edge or Brave

  1. Extract the downloaded ZIP and move the chatgpt-browser-bridge folder somewhere permanent. No checkout, build or local server is required.
  2. Open chrome://extensions, brave://extensions or edge://extensions in your desktop browser. Enable Developer mode and choose Load unpacked.
  3. Select the extracted folder containing manifest.json. Keep it in place while installed.
  4. Open ChatGPT and sign in in the same browser profile.
  5. Reload CV Anonymiser. The tailoring panel should show Browser extension connected; use Check to retry.

Already installed? Update your existing copy

Version 0.1.1 adds support for https://cv-tailor-ddd12.web.app/. An older extension can be enabled in Chrome but unable to connect on this domain.

  1. Download and extract the current extension ZIP. In chrome://extensions, open ChatGPT Browser Bridge’s Details and find its Loaded from folder.
  2. Replace the extension files in that existing folder with the newly extracted files. Keep the folder in the same location so Chrome keeps your existing installation.
  3. Click Reload for ChatGPT Browser Bridge. Its version should read 0.1.1 or newer, and its site access should include cv-tailor-ddd12.web.app.
  4. Reload the CV app and choose Check connection again if needed. Sign in to ChatGPT in the same browser profile. No CV details need to be sent for the extension connection check.

The guided master builder checks the extension before showing CV questions. Live advice starts on; you can turn it off after connecting. Your step and saved notes remain available if the connection drops.

Tailor a CV

  1. Import or open your full master CV. Set up and review your private redactions.
  2. Use Project ranking to order projects by personal priority and add notes about effort or limitations. These preferences save with your full master, browser workspace and private backup.
  3. Paste only the job description and choose Tailor CV with ChatGPT. The CV headline stays Software Engineer; no Company or Role fields need filling.
  4. Keep the app open while the extension scores the catalogue internally, returns only your requested top-scoring projects and pastes the tailored drafting prompt into the same dedicated ChatGPT chat. That second prompt contains the CV template, core experience and only the selected full project entries, reusing the job description from the first prompt. No tailoring file upload is needed. Scores are estimates of fit, separate from your personal ranking.
  5. Review Project relevance. Compare the selected scores, swap or reorder picks, then use Draft selected projects to draft your chosen list.
  6. Review the returned CV. In Refine generated text, edit Core skills or a project manually, or give ChatGPT feedback for that block. Review and apply each proposed revision. Resolve or acknowledge any Draft check notices before exporting or saving.
  7. Save the application or choose Compile PDF yourself when ready. Check the actual page count and layout.

Only prepared prompts are sent through the extension. Your private redaction key stays in this app. Details you have not selected for redaction may still appear in the prompts, including project notes and revision feedback. You can review selection and drafting prompts using the manual controls and copy individual revision prompts before sending them.

When it needs attention

Sign-in, browser verification, a changed ChatGPT layout or an uncertain Send can pause a request. Inspect its dedicated ChatGPT tab before starting another run. Account message limits wait through shared cooldowns. Cancel tailoring stops pending work; edits to the current workspace also cancel the run and keep your edits.

After installing or reloading the extension, reload this page’s CV app. Use the same browser profile for the app, extension and ChatGPT. The original copy-and-paste workflow remains under Copy and paste prompts manually.

The bridge supports the hosted CV Anonymiser addresses and local development at http://localhost or http://127.0.0.1. Unpublished changes can be tried with npm run dev -- --host 127.0.0.1 in the CV repository.
