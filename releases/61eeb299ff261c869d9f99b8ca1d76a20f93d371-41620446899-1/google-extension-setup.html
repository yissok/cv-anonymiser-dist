Set up CV Google Connection

Open the setup wizard to install both extensions, or download the Google extension ZIP directly.

Install on this computer

  1. Use desktop Brave or Chrome. Extract the ZIP and move its cv-google-connection folder somewhere permanent.
  2. Open brave://extensions or chrome://extensions in the address bar. Enable Developer mode, choose Load unpacked and select the folder containing manifest.json. Keep that folder in place.
  3. Reload the CV app. Choose Open Google connection in the wizard, then Connect with extension. Sign in using the Google account that owns the linked CV library.
  4. If this account needs its initial selected-file grant, choose Choose linked Sheet. That grant uses the restricted Picker key supplied by the app owner. Existing grants do not require a new key on each device.

Reconnect or update

If Google needs renewed sign-in, choose Reconnect Google or Connect with extension. Brave’s silent renewal depends on the Google session in that profile. Closing the browser, revoked access or account policy can require you to reconnect.

For an extension update, replace the files in its installed folder with the new ZIP’s files, reload the extension on the extensions page, then reload the CV app. If detection fails, check that both the app and extension use this browser profile.
